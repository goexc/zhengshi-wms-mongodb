# Windows 客户端发布验收清单

## 自动化门禁

- `go test -count=1 ./...`
- `go vet ./...`
- `go mod tidy -diff`
- 线上只读契约测试，不启用任何 mutation 环境变量
- `amd64`、`arm64` 构建完成，PE 架构、GUI subsystem、资源节和版本信息正确
- 正式发布使用 `-RequireSignature`，主程序和安装包签名状态均为 `Valid`
- SHA256 清单与最终签名后的文件一致
- 安装包使用固定 AppId；从上一正式版本覆盖升级后，快捷方式、用户配置和 DPAPI 会话行为符合预期
- 客户端源代码中的静态 HTTP 方法/路径全部通过 `api/main.api` 自动契约审计，动态契约继续由关键清单覆盖
- `scripts/verify-release.ps1` 同时完成测试、静态检查、整洁性、双架构 PE/资源/哈希核验；正式发布另启用签名和安装包门禁

## Windows 实机

- amd64 Windows 10/11 启动、登录、保持登录、退出和重新登录
- 同一 Windows 登录会话重复启动客户端时，第二个实例恢复、前置并聚焦已有主窗口；仅在定位失败时显示提示，不再打开第二个主窗口
- ARM64 Windows 11 真机启动，不以交叉编译结果代替运行验收
- 100%、125%、150%、200% 显示缩放；主窗口、编辑标签、图纸窗口无内容截断
- 双显示器不同 DPI 间移动窗口，字体、表格、标签关闭入口和图纸缩放保持正常
- 纯键盘完成菜单切换、筛选、查询、新建、保存、关闭标签和统一检索
- 物料图纸与附件预览可用 Ctrl+加减号按 10% 缩放、Ctrl+0/1 切换适应宽度/100%、Ctrl+L/R 旋转
- Windows 高对比度模式下，文本、焦点、禁用状态和错误状态可辨识
- 1024 像素级可用宽度及 125%—200% 缩放下，入库/出库操作行、流程行和分页行均可操作
- 调整主要表格列宽/顺序和主工作区、出库主从表分隔比例，重启后同账号同 API 恢复；切换账号或 API 不串用布局
- 在每台验收设备上运行 `scripts/inspect-device-environment.ps1 -Executable <exe>`，将环境与产物证据随验收记录保存；该输出本身不代替人工操作结论

## 网络与恢复

- 启动时断网：允许重试或切换账号，不清除仍有效的加密会话前不误报登录成功
- 人工损坏普通配置主文件和 DPAPI 会话主文件后，可从最近一次有效备份恢复；备份中不出现明文 Token
- 查询中断：旧响应不覆盖新查询，页面提供刷新恢复路径
- 后台任务窗口能列出库存、入库、出库查询导出并安全取消；取消后按钮恢复、任务最终移除且不遗留 `.partial` 文件
- 写请求中断：操作复核显示“结果待确认”，重启后仍能恢复，不自动重提
- 人工触发后台任务异常：主窗口不中断，显示故障编号；若任务涉及写请求，可从操作复核确认线上结果
- 人工核对后可移除本机待确认记录，且不会产生任何后端写请求
- 日志轮转后最多保留当前日志和 3 份备份，不出现密码、Token、请求体或响应体

## 打印与导出

- 真实 A4 打印机：入库核对单、出库清单、签收摘要分页正确
- 标签打印机：大字号单号完整，无未经后端定义的条码编码
- 图纸在不同纸张方向和可打印区域内等比缩放
- 取消打印、打印机离线、缺纸时不误报成功
- Excel 导出当前筛选、5000 条上限、进度、取消和网络失败路径正确；取消或失败后不留下 `.partial` 文件，也不覆盖已有目标文件
- 物料、入库、出库、合作伙伴、仓储位置及客户交易的图片上传可取消，取消后原图/附件集合不变；头像仅允许在图片上传阶段取消

## 线上写操作

- 仅使用负责人指定的一次性测试单据和测试主数据
- 可逆流程优先：入库新建/编辑/驳回/删除、预发货新建/删除、测试主数据停用
- 收货、库存扣减、极速出库、签收、客户应收和授权变更必须人工逐项确认，不做无人值守 mutation
- 每次写入均核对权限、提交前快照、服务端响应、线上回读和清理结果
