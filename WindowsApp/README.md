# 正时 WMS Windows 客户端

原生 Windows 客户端，基于 Go 和 `lxn/walk`，直接连接线上 API：

`https://wmsx.api.goexc.cn:1443`

## 当前范围

- 线上账号登录、退出
- 登录窗口固定使用配置的服务地址，不向普通用户展示地址输入框
- 使用 Windows DPAPI 加密保持登录状态，启动时在线复核身份与权限
- 当前 Windows 登录会话内只允许运行一个客户端实例；重复启动会恢复、前置并聚焦已有主窗口，定位失败时才显示明确提示，避免同时操作同一账号数据
- 普通配置和 DPAPI 会话使用原子替换与有效备份；主文件写入中断或损坏时自动恢复最近一次有效状态，令牌备份仍为当前 Windows 用户范围的 DPAPI 密文
- 账号资料与权限菜单初始化
- 权限驱动的左侧功能菜单，以及带“×”关闭入口、可从菜单重新打开并保留本次运行状态的业务标签页
- 按当前账号和 API 环境保存已打开页面、当前页面、窗口位置和尺寸、左侧菜单状态、分页密度、主要表格列宽/顺序、主工作区及主从表分隔比例，以及库存视图/入库状态/出库队列等固定枚举筛选；窗口恢复时自动约束在当前多显示器可视区域内；不保存单号、物料、合作伙伴、仓位等业务筛选值，不缓存已加载数据或编辑草稿
- 首次只创建默认工作台，恢复会话时只创建上次打开的顶层标签；仅在标签首次切换到前台时初始化页面和筛选依赖，避免启动时同时请求全部业务模块
- 提供统一扫码与业务检索页，可按当前菜单权限自动识别物料、入库单和出库单；扫描枪输入后按 Enter 即可查询，最近检索只保存在本次运行内存中
- 仓库作业台按权限汇总入库待审核、审核不通过、部分入库及出库执行待办，支持失败降级和点击进入对应状态队列
- 物料按分类、名称、型号、规格、材质、表面处理和强度等级组合查询，图纸列以“✔/✘”标记有无图纸
- 物料中心按现有按钮权限支持新增、编辑和图纸上传；分类采用独立可关闭标签页维护根分类、子分类及状态，不提供物料、分类或价格删除
- 图片素材中心按现有菜单权限查询、分页、上传、取消上传、复制引用并异步显示缩略预览；关闭预览或切换素材会取消旧图片下载；不提供素材删除
- 物料、合作伙伴、仓储结构、入库单和出库单编辑器支持选择已有线上素材，也保留本地图片上传入口；本地上传期间可再次点击上传按钮取消，取消后保留原图或原附件集合
- 新增物料报价按客户、首次交付日期、报价状态、物料名称及型号查询，支持服务端 CSV 导出、报价历史和现有重建任务接口
- 报价编辑采用独立可关闭标签页，覆盖详细/简单报价、Web 端成本项、有效期、税率、提交、最终定价、作废与单张报价导出；金额以服务端回读为准
- 库存按入库类型、物料名称/型号及仓库、库区、货架、货位级联查询
- 库存页支持“当前库存”和“库存批次历史”切换
- 入库单按单号、状态、类型、供应商和客户查询，支持结构化详情和批次主从收货记录
- 入库单支持按现有权限和状态规则新建、编辑、审核、删除；新建/编辑采用独立可关闭标签页
- 入库编辑支持物料搜索、单价、预计数量、可选计划仓位和图片附件；编辑态的单号、类型保持只读
- 入库单、出库单详情支持线上图片附件预览；支持适应宽度、Ctrl+滚轮或 Ctrl+加减号按 10% 缩放、Ctrl+0/1 切换适应宽度/100%，以及 Ctrl+L/R 左右旋转
- 批次收货支持承运商、运费、其他费用、物料数量和统一仓储位置
- 批次收货窗口先打开再异步加载仓储位置和承运商；仓储位置失败可重试，承运商失败可不选承运商继续
- 出库执行队列按单号、虚拟状态队列、类型、供应商、客户和签收日期查询
- 出库单物料明细和现有状态/打包/称重标记展示
- 按 `outbound:order:add` 权限新建预发货出库单，使用独立可关闭标签页，支持物料选择、历史价格参考、零价提示、图片附件及提交后在线复核
- 按 `outbound:order:add` 权限提供“极速出库”，仅允许销售、样品和赠品出库；一次提交接入现有 `/outbound/fast_departure` 接口，明确提示库存补足、库存扣减、签收和客户应收影响
- 极速出库支持客户、物料、单价、数量及拣货/打包/称重/出库/签收日期录入；校验自然日时间链，提交响应不确定时按单号回读，无法确认时锁定页面防止重复写入
- 按 `outbound:order:delete` 权限删除仍处于预发货状态的出库单；删除前重新读取状态，删除后确认单据不再存在，写操作不自动重试
- 按现有接口支持确认并分配库存、拣货、打包、称重、出库和签收附件上传
- 按 `outbound:order:revise` 权限接入现有出库核价/调价接口，支持历史价格参考、提交前快照检查和提交后价格复核
- 出库报表按客户和签收日期查询，支持按单据、按物料导出 Excel
- 当前库存、库存批次历史、入库单和出库执行支持导出当前筛选的全部查询结果；客户端分批读取现有接口并显示进度，本地生成含查询时间、筛选条件和数据来源说明的 Excel，单次上限 5000 条；用户可取消导出，目标文件采用同目录临时文件原子替换，取消或失败不会留下半成品
- 主窗口统一显示正在执行的后台查询导出任务，可查看用时并从任务窗口安全取消；线上写操作不进入全局取消入口，避免把请求取消误解为服务端事务回滚
- 合作伙伴覆盖供应商、客户和承运商查询，并按现有按钮权限支持新增、编辑及非删除状态变更；客户新增的期初应收会在提交前明确二次确认
- 物料详情支持只读历史价格；客户应收采用独立可关闭标签页展示交易流水、当前应收和流水附件
- 客户应收工作台接入现有回款、退货冲减接口；使用客户级幂等键，方向和余额由服务端决定，超时后保留原幂等键供人工核对或重试
- 物料详情可查看库存位置；库存记录可在只读可关闭标签中追溯来源入库单和收货批次；出库执行与出库报表明细可在只读可关闭标签中追溯对应出库单，来源筛选、分页及选中状态保持不变
- 仓储结构页展示仓库、库区、货架、货位层级树，支持 Web 端已有类型筛选，并按现有按钮权限新增、编辑及变更非删除状态
- 合作伙伴和仓储资料编辑使用独立可关闭标签页，图片上传失败会恢复原值，编辑提交前检查线上更新时间，提交成功后回读复核
- 按账号菜单权限提供系统管理工作台：用户查询/新增/编辑/角色分配/启停/密码重置，部门树查询/新增/编辑，角色查询/新增/编辑/启停以及菜单/API 授权
- 菜单和 API 目录在 Windows 客户端中只读；角色授权提交后立即回读并按 ID 集合复核，用户、部门和角色均不提供删除入口
- 近期线上操作复核中心在请求发送前记录“正在提交”，结束后更新同一记录并区分“服务端成功”“服务端拒绝”和“结果待确认”；复核动作只调用现有查询接口回读，不提供自动重提
- 未完成和结果待确认的操作按 API 环境及账号隔离，使用 Windows DPAPI 加密保留 7 天、最多 100 项；异常退出后可恢复，人工核对后可从本机日志移除
- 单据中心支持在线生成入库收货核对单、出库物料清单、出库签收摘要、物料图纸和大字号单号标签；打印前强制重新读取线上数据，失败时清空旧预览并停止打印
- 打印使用 Windows 标准打印机选择界面和原生 GDI 输出；物料图纸自动适应可打印区域，单号标签以大字号文本输出，不生成未经后端定义的条码业务编码
- 个人中心只读展示当前账号资料，支持通过独立头像接口更新头像并在线回读；头像图片上传阶段可取消，进入头像写入和回读阶段后禁止取消；支持修改密码，成功后清除 DPAPI 登录缓存、退出当前会话并返回登录窗口
- 筛选区域统一采用每行最多 4 个表单项的桌面工作台布局
- 入库和出库工作台将单据操作、执行流程及分页状态分行展示，降低高 DPI 和较窄窗口下的按钮截断风险；全局中性说明文字和成功、警告、错误状态使用语义色，Windows 高对比度模式下自动使用系统文本色
- 物料、库存和入库列表支持 10/20/50/100 条分页；出库列表按接口限制支持 10/20/50 条分页；物料、库存、入库、出库及报价列表均可按总页数直接跳转
- 批次收货数量、状态和仓储位置校验
- 线上写操作二次确认、防重复点击、提交前状态刷新和提交后服务端回读
- 网络或响应异常时不自动重试，提示刷新服务端状态后再决定下一步
- 统一区分网络超时、权限不足和业务校验错误；普通查询、写请求、图片传输和文件导出采用不同客户端超时，调用方主动取消优先，写请求仍不自动重试；身份返回 401 时立即清除 DPAPI Token 并返回登录页
- 收货提交后的批次记录与库存复核
- 按钮级入库和出库权限
- 查询请求取消，避免旧响应覆盖新查询
- 支持 `F5` 刷新当前页、`Ctrl+K` 打开统一检索、`Ctrl+F` 定位筛选条件、`Ctrl+N` 新建当前模块单据、`Ctrl+S` 保存当前编辑页、`Ctrl+W` 关闭当前标签、`Ctrl+M` 展开或收起左侧功能菜单
- 本地脱敏请求日志和只读诊断摘要；可复制版本、运行环境、API 地址和最近请求日志，或原子保存包含摘要及轮转日志的 ZIP 诊断包，不包含密码或身份 Token
- 请求日志单文件最多 5 MB，轮转保留 3 份；主线程及所有客户端后台任务的未处理异常只记录故障编号、任务来源、异常类型和堆栈，不记录异常文本；后台故障会安全终止当前任务，并提示用户到操作复核确认可能受影响的线上写入
- 线上环境醒目标识
- 记住手机号但不保存密码；保持登录时仅使用 Windows DPAPI 加密保存 Token

客户端只调用现有后端接口，不修改后端业务逻辑。物料、报价、入库单和出库单写操作继续由服务端权限和状态规则最终校验；现有列表接口不返回原计划仓位，因此编辑已有入库单时客户端会明确提示仓位无法回填，用户可按实际需要重新选择。
仍不提供出库单编辑、退货出库建单、库存调整、图片删除、客户应收重算、主数据删除、菜单/API 目录编辑、系统用户/部门/角色删除和入库报表功能。退货出库现有 DTO 校验与业务逻辑对客户/供应商的要求不一致，客户端不会猜测或绕过；完整个人资料编辑仍不开放，避免现有接口字段不完整导致账号角色或头像被意外覆盖，头像仅通过独立 `PATCH /account/avatar` 接口更新。
出库写操作必须由账号同时具备相应按钮权限，并继续接受服务端路径、方法和状态规则校验。

## 开发验证

```powershell
go test ./...
go vet ./...
go mod tidy -diff
.\scripts\verify-release.ps1
```

如需同时执行线上只读契约验证，应先设置 `WMS_ONLINE_BASE_URL`、`WMS_ONLINE_IMAGE_BASE_URL`、`WMS_ONLINE_MOBILE`、`WMS_ONLINE_PASSWORD`，然后运行 `.\scripts\verify-release.ps1 -OnlineReadOnly`。脚本发现任何 mutation 环境变量时会拒绝执行。

## 构建

```powershell
.\scripts\build.ps1
```

客户端仅支持 64 位 Windows，构建架构为 `amd64`（默认）和 `arm64`；不再提供 32 位 `386` 构建。

```powershell
.\scripts\build.ps1 -Architecture amd64
.\scripts\build.ps1 -Architecture arm64
```

产物位于 `dist/`。构建脚本固定使用 `goversioninfo v1.7.0`，会嵌入应用图标、Common Controls 6、Per-Monitor DPI manifest 和 Windows VERSIONINFO；客户端内部同时嵌入版本/构建时间/Git 提交号，并使用 Windows GUI subsystem。
构建时会把根目录的 `logo.png` 转换为包含 16 至 256 像素多个尺寸的 Windows 图标并嵌入 EXE。

开发构建允许未签名，但会明确输出签名状态并生成对应架构的 `SHA256SUMS-*.txt`。正式发布可使用当前 Windows 用户证书库中的代码签名证书，并强制拒绝未签名产物：

```powershell
.\scripts\build.ps1 -Architecture amd64 -CertificateThumbprint "证书指纹" -RequireSignature
```

安装包使用稳定 AppId 的 Inno Setup 6 按当前用户安装到 `%LOCALAPPDATA%\Programs\ZhengshiWMS`，不会请求管理员权限；同架构新版本会沿用原安装目录并关闭运行中的旧客户端后原位升级，用户配置和 DPAPI 登录缓存位于安装目录之外，不随卸载程序删除。安装包与主程序使用同一证书签名：

```powershell
.\scripts\package.ps1 -Architecture amd64 -CertificateThumbprint "证书指纹" -RequireSignature
```

未提供真实证书或系统未安装 `signtool.exe` / Inno Setup 时，脚本会明确失败，不会生成伪签名发布包。

服务器地址默认固定为线上地址，可由 `ZHENGSHI_WMS_API_BASE_URL` 环境变量覆盖。普通配置保存在当前 Windows 用户的配置目录中；密码从不保存，保持登录时 Token 使用当前 Windows 用户范围的 DPAPI 加密后保存。
契约测试会通过 Go AST 扫描客户端源代码中的静态 HTTP 方法和路径，并与仓库中的 `api/main.api` 注册表核对；动态方法路径仍由显式关键契约清单补充覆盖。
