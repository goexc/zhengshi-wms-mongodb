# 正时 WMS Windows 客户端

原生 Windows 客户端，基于 Go 和 `lxn/walk`，直接连接线上 API：

`https://wmsx.api.goexc.cn:1443`

## 当前范围

- 线上账号登录、退出
- 登录窗口固定使用配置的服务地址，不向普通用户展示地址输入框
- 使用 Windows DPAPI 加密保持登录状态，启动时在线复核身份与权限
- 账号资料与权限菜单初始化
- 权限驱动的左侧功能菜单，以及可关闭、可从菜单重新打开的业务标签页
- 物料按分类、名称、型号、规格、材质、表面处理和强度等级组合查询
- 库存按入库类型、物料名称/型号及仓库、库区、货架、货位级联查询
- 库存页支持“当前库存”和“库存批次历史”切换
- 入库单按单号、状态、类型和供应商查询，支持结构化详情和批次收货记录
- 批次收货支持承运商、运费、其他费用、物料数量和统一仓储位置
- 出库执行队列按单号、虚拟状态队列、类型、供应商、客户和签收日期查询
- 出库单物料明细和现有状态/打包/称重标记展示
- 按现有接口支持确认并分配库存、拣货、打包、称重、出库和签收附件上传
- 筛选区域统一采用每行最多 4 个表单项的桌面工作台布局
- 物料、库存和入库列表支持 10/20/50/100 条分页；出库列表按接口限制支持 10/20/50 条分页
- 批次收货数量、状态和仓储位置校验
- 线上写操作二次确认、防重复点击、提交前状态刷新和提交后服务端回读
- 网络或响应异常时不自动重试，提示刷新服务端状态后再决定下一步
- 收货提交后的批次记录与库存复核
- 按钮级入库和出库权限
- 查询请求取消，避免旧响应覆盖新查询
- 本地脱敏请求日志
- 线上环境醒目标识
- 记住手机号但不保存密码；保持登录时仅使用 Windows DPAPI 加密保存 Token

客户端只调用现有后端接口，不修改后端业务逻辑。仍不提供入库/出库单新增、修改、删除、快速出库、库存调整、主数据维护、权限管理和报表功能。
出库写操作必须由账号同时具备相应按钮权限，并继续接受服务端路径、方法和状态规则校验。

## 开发验证

```powershell
go test ./...
go vet ./...
```

## 构建

```powershell
.\scripts\build.ps1
```

产物位于 `dist/`。构建脚本会嵌入 Common Controls 6 和 Per-Monitor DPI manifest，并使用 Windows GUI subsystem。
构建时会把根目录的 `logo.png` 转换为包含 16 至 256 像素多个尺寸的 Windows 图标并嵌入 EXE。

服务器地址默认固定为线上地址，可由 `ZHENGSHI_WMS_API_BASE_URL` 环境变量覆盖。普通配置保存在当前 Windows 用户的配置目录中；密码从不保存，保持登录时 Token 使用当前 Windows 用户范围的 DPAPI 加密后保存。
